==============================================================
            팜코치 관리 프로그램  -  실행 전 가이드라인
==============================================================

이 글을 순서대로 따라 하면 누구나 팜코치 관리 프로그램을
켤 수 있어요. 천천히 하나씩 해 보세요.


--------------------------------------------------------------
 0. 준비물
--------------------------------------------------------------
  - 윈도우 10 또는 윈도우 11 컴퓨터
  - 인터넷 연결 (처음 설치할 때 꼭 필요해요)
  - 팜코치 관리자 사이트 아이디와 비밀번호
  - 깃허브(GitHub) 계정 (사이트에 올리기 할 때 한 번 필요해요)


--------------------------------------------------------------
 1. 압축 풀기  (꼭 먼저 해야 해요!)
--------------------------------------------------------------
  1) 받은 압축파일 [팜코치_런처.zip] (링크로 받았다면 [farmcoach-launcher.zip])
     에 마우스를 올리고
     "오른쪽 버튼"을 눌러요.
  2) [모두 압축 풀기...] 를 눌러요.
  3) [압축 풀기] 버튼을 눌러요.
  4) [팜코치_런처] 라는 폴더가 생겨요. 그 폴더를 열어요.

  ※ 압축을 풀지 않고 zip 안에서 바로 더블클릭하면 안 돼요.
  ※ 폴더는 바탕화면이나 문서 폴더처럼 찾기 쉬운 곳에 두세요.

  폴더 안에는 이렇게 3개가 있어요.
    - 팜코치_런처_실행.bat   ← 이것을 더블클릭해서 시작해요
    - launcher.pyw            ← 런처 본체 (건드리지 않아요)
    - 실행전_가이드라인.txt   ← 지금 읽고 있는 이 글


--------------------------------------------------------------
 2. 시작하기
--------------------------------------------------------------
  1) [팜코치_런처_실행.bat] 을 더블클릭해요.

  2) 파란 창 "Windows의 PC 보호" 가 뜨면 (처음 한 번만 떠요)
       → 글자 [추가 정보] 를 눌러요
       → 아래에 생긴 [실행] 버튼을 눌러요
     (인터넷에서 받은 파일이라 윈도우가 한 번 물어보는 거예요.)

  3) 검은 창이 뜨고 아래처럼 물어볼 수 있어요.
       "파이썬 Python 프로그램이 없어서 먼저 설치해야 해요.
        지금 자동으로 설치할까요?  Y = 예 / N = 아니오"
     → 키보드에서 Y 를 눌러요.
     → "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 [예]
     → 몇 분 기다리면 설치가 끝나요.

  4) 이어서 Git 프로그램도 같은 방법으로 물어보면
     → Y 를 누르고, 창이 뜨면 [예] 를 눌러요.

     ※ 파이썬과 Git 이 이미 있는 컴퓨터는 이 질문 없이
        바로 다음 단계로 넘어가요.

  5) "팜코치 런처" 창이 열려요.


--------------------------------------------------------------
 3. 런처에서 설치하고 실행하기
--------------------------------------------------------------
  런처 창 모양
    ┌───────────────────────────────┐
    │ 관리자 ○○○ 님        [다시 확인] │
    │ ┌───────────────────────────┐ │
    │ │ 팜코치 관리 프로그램            │ │
    │ │ 최신입니다 (1.3.0)            │ │
    │ │ [업데이트]  [실행]             │ │
    │ └───────────────────────────┘ │
    │ ▓▓▓▓▓▓▓▓▓▓▓▓ (진행 막대)          │
    │ (기록이 나오는 칸)                │
    └───────────────────────────────┘

  1) 처음에는 "아직 설치되지 않았어요" 라고 나오고
     초록색 [설치하기] 버튼이 생겨요. → 눌러요.
  2) 아래 기록 칸에 "설치 완료!" 가 나올 때까지 기다려요.
     (인터넷 속도에 따라 1~3분)
  3) [실행] 을 눌러요.
  4) 인터넷 창(크롬 등)에 "팜코치 관리 프로그램" 화면이 열려요. 끝!

  다음부터는
    - [팜코치_런처_실행.bat] 더블클릭 → [실행] 만 누르면 돼요.
    - "새 버전이 있어요" 라고 주황색 글씨가 나오면
      [업데이트] 를 먼저 누르고 → [실행] 을 눌러요.
    - 이미 켜져 있으면 [실행] 버튼이 [열기] 로 바뀌어요.
    - 프로그램을 끄고 싶으면 [프로그램 끄기] 글자를 눌러요.


--------------------------------------------------------------
 4. 관리 프로그램을 처음 쓸 때 (한 번만)
--------------------------------------------------------------
  [ 팜코치에서 불러오기 ]
    1) 위쪽 [⟳ 팜코치에서 불러오기] 를 눌러요.
    2) 팜코치 관리자 사이트 아이디/비밀번호를 넣어요.
       "이 컴퓨터에 기억하기" 를 켜 두면 다음부터 안 물어봐요.
       (비밀번호는 이 컴퓨터에만 저장되고 인터넷에 올라가지 않아요.)

  [ 사이트에 올리기 ]
    1) 처음 [⬆ 사이트에 올리기] 를 누르면
       "Connect to GitHub" (깃허브에 연결) 창이 떠요.
    2) [Sign in with your browser] (브라우저로 로그인) 를 눌러요.
    3) 인터넷 창에서 깃허브 계정(xkxkrh)으로 로그인하고
       [Authorize] (허락하기) 를 눌러요.
    4) 다시 [⬆ 사이트에 올리기] 를 누르면 올라가요.
       이것도 한 번만 하면 다음부터는 안 물어봐요.


--------------------------------------------------------------
 5. 바탕화면에 바로가기 만들기 (선택)
--------------------------------------------------------------
  1) [팜코치_런처_실행.bat] 에 마우스 오른쪽 버튼
  2) [추가 옵션 표시] (윈도우 11) → [보내기] → [바탕 화면에 바로 가기 만들기]
  3) 이제 바탕화면에서 바로 켤 수 있어요.


--------------------------------------------------------------
 6. 자동 설치가 안 될 때 (직접 설치하는 방법)
--------------------------------------------------------------
  검은 창에 "자동 준비를 끝내지 못했어요" 가 나오면
  아래 두 개를 직접 설치하고 [팜코치_런처_실행.bat] 을 다시 눌러요.

  [ 파이썬(Python) 설치 ]
    1) 인터넷 창 주소칸에  https://www.python.org/downloads/  를 입력해요.
    2) 노란 버튼 [Download Python 3.x.x] 를 눌러 파일을 받아요.
    3) 받은 파일을 더블클릭해요.
    4) ★ 첫 화면 맨 아래 [Add python.exe to PATH] 칸에
         꼭 체크(✔)를 해요! ★
    5) [Install Now] 를 누르고 → [예] → 끝나면 [Close].

  [ Git 설치 ]
    1) 인터넷 창 주소칸에  https://git-scm.com/download/win  를 입력해요.
    2) [Click here to download] 를 눌러 파일을 받아요.
    3) 받은 파일을 더블클릭 → [예].
    4) 설치 화면에서는 아무것도 바꾸지 말고
       [Next] 를 계속 누르다가 [Install] → 끝나면 [Finish].

  ※ 설치가 끝나면 컴퓨터를 한 번 다시 켜 주면 더 확실해요.


--------------------------------------------------------------
 7. 이럴 땐 이렇게
--------------------------------------------------------------
  Q. 더블클릭했는데 검은 창이 잠깐 떴다 사라지고 아무것도 안 돼요.
     → 압축을 풀었는지 확인해요 (1번). zip 안에서는 실행이 안 돼요.

  Q. 런처에 "Git 프로그램이 필요해요" 라고 나와요.
     → 6번의 Git 설치를 하고 [다시 확인] 을 눌러요.

  Q. 런처에 "최신 버전을 확인하지 못했어요" 라고 나와요.
     → 인터넷이 연결되어 있는지 확인하고 [다시 확인] 을 눌러요.

  Q. 업데이트할 때 "내 변경과 겹침" 이라고 나와요.
     → 관리 프로그램에서 [⬆ 사이트에 올리기] 를 먼저 한 뒤
       런처에서 [업데이트] 를 다시 눌러요.

  Q. 관리 프로그램 화면을 닫아 버렸어요.
     → 런처에서 [열기] 를 누르거나,
       인터넷 창 주소칸에  http://127.0.0.1:8765  를 입력해요.

  Q. 컴퓨터 두 대에서 같이 써도 되나요?
     → 돼요. 다만 같은 시간에 두 곳에서 고치면 겹칠 수 있으니
       한 곳에서 [사이트에 올리기] 를 한 뒤
       다른 곳에서 런처 [업데이트] 를 누르고 쓰세요.

  Q. 프로그램은 어디에 설치돼요?
     → 이 폴더 안의 [farmcoach] 폴더에 들어가요.
       이 폴더를 지우면 이 컴퓨터에서 고친 내용도 지워져요.
