# 팜코치 B2B 상품리스트

> 담당자가 바뀌면 먼저 [인수인계.md](인수인계.md) 를 보세요.

셀러들이 보는 상품 사이트와, 그 내용을 채우는 관리 프로그램입니다.

## 사용법 (3단계)

1. **`팜코치_관리프로그램.bat` 더블클릭** → 관리 화면이 브라우저에 열려요. (검은 창은 닫지 마세요. 닫으면 프로그램이 꺼져요.)
2. **⟳ 팜코치에서 불러오기** → 팜코치B2B 관리자 사이트에서 상품·옵션·가격·품절·배송비를 읽어와요. 관리자 사이트 내용은 바꾸지 않아요.
3. 필요하면 고치고(상품 편집 / 공지사항 / MD추천), **⬆ 사이트에 올리기** → 1~2분 뒤 셀러 사이트에 반영돼요.

- 고친 내용은 자동 저장되고, 다시 불러와도 그대로 남아요.
- 상품을 새로 등록하거나 품절시켰으면: 불러오기 → 올리기만 하면 돼요.
- **👀 셀러 사이트 미리보기**로 올리기 전에 어떻게 보일지 확인할 수 있어요.

## 폴더 구성

| 폴더/파일 | 내용 |
|---|---|
| `docs/` | 셀러 사이트 (깃허브 Pages가 이 폴더를 보여줌). `data.json`에 상품 정보가 들어있음 |
| `manager/` | 관리 프로그램 (파이썬 기본 기능만 사용, 따로 설치할 것 없음) |
| `manager/data/edits.json` | 내가 고친 내용, 공지사항, MD추천 |
| `manager/config.json` | 관리자 로그인 정보 — **내 컴퓨터에만 있고 깃허브에 안 올라감** |

## 규칙

- 셀러 사이트에는 최신 등록 상품이 맨 위에 나와요.
- 관리자 사이트에서 '노출하지않습니다'인 그룹·옵션은 품절로 표시돼요.
- '특정 거래처에게만 노출'로 설정된 그룹은 자동으로 셀러 사이트에서 숨겨요. (상품 편집에서 '항상 보이기'로 바꿀 수 있어요)
- 원가는 읽지도, 올리지도 않아요. 셀러 사이트에는 기본공급가만 나와요.
