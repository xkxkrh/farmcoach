# 발주 가이드 영상 녹화 도구

크롬을 자동으로 움직이며 팜코치 발주 사이트(partner-app)를 녹화하고, 자막·마우스 표시·빨간 네모를 넣어 MP4로 만듭니다.
추가 설치 없음 (크롬 + 파이썬 기본 기능). 실제 주문/결제/충전 신청 버튼은 절대 누르지 않고 가리키기만 합니다.

## 순서
1. `py extract_slides.py "<발주 가이드 PDF 경로>"` → `slides/` 에 PDF 화면 사진 (주문 후·결제 후 화면 예시용)
2. `py launch.py` → 녹화용 크롬 창이 뜸 (별도 프로필). **셀러 계정으로 직접 로그인** 후 창을 그대로 둠
3. 시험 실행: `py record.py --dry` (녹화 없이 장면만 돌려 봄)
4. 녹화: `set PRODUCT=(팜)상품옵션명` + `set SEARCH=검색어` 후 `py record.py`
   - 제품 매칭 장면은 **아직 매칭된 적 없는 옵션**이어야 검색 장면이 나옴 (한 번 고르면 셀러 계정에 매칭이 저장됨)
   - 녹화 1회마다 셀러 계정 '엑셀 주문입력 리스트'에 업로드 기록이 하나 남음 (주문은 생기지 않음)
5. 결과 `out/order-guide-final.mp4` → `docs/media/order-guide.mp4` 로 복사 → 관리 프로그램에서 사이트에 올리기

## 파일
| 파일 | 역할 |
|---|---|
| record.py | 장면 대본 + 녹화(크롬 screencast) + 인코딩 + 길이 보정 + 일반 MP4 변환 |
| overlay.js | 화면 위 자막·마우스 화살표·빨간 네모·제목 카드 |
| enc2.html | 녹화된 장면 사진들을 크롬 MediaRecorder로 MP4 인코딩 (1600×900, 2.2Mbps) |
| fixmp4.py | 크롬이 만든 조각 MP4에 전체 길이 기록 |
| remux.py | 조각 MP4 → 일반 MP4(앞부분에 목차) — 탐색이 잘 되게 |
| cdp.py | 크롬 원격 조종(DevTools Protocol) 최소 구현 |
| launch.py / step.py / peek.py | 녹화용 크롬 열기 / 한 단계씩 조작 / 화면 찍어 보기 |
| play_check.py | 완성 영상을 크롬에서 재생·탐색 확인 (부분 전송 지원 서버 포함) |
| order_template.xlsx | 발주 사이트의 공통 엑셀 양식 (샘플 주문 파일을 여기서 만듦) |

## 알아둘 점
- 화면은 1920×1080으로 녹화 (사이트가 넓은 화면 기준).
- 인코딩 탭은 앞에 있어야 함(뒤에 있으면 크롬이 느리게 그림). 캐시를 끄고 프레임마다 `?r=` 를 붙여 옛 장면이 섞이지 않게 함.
- 영상 확인은 부분 전송(Range)을 지원하는 서버로 해야 탐색이 정확함 (깃허브 Pages는 지원).
